# 라르고 종가베팅 v6 그림자 규칙

v6는 v5를 즉시 교체하지 않습니다. 7월 일봉 대용 표본에서 손실 후보를 줄이는 조건을 만들고, 8월의 정확한 15시 18분·09시 06분 호가 표본에서 같은 조건을 다시 계산했습니다.

## 변경 이유

- v5 직접 재료형은 재료가 해당 기업에 직접 연결되는지와 부정 문맥을 충분히 막지 못했습니다.
- 직접 재료가 이미 당일 급등에 반영된 경우와 아직 반영되지 않은 경우를 한 경로로 섞었습니다.
- 추세형은 당일 상승률과 소화율만으로 통과해 마감 구조와 테마 확산 확인이 부족했습니다.
- 하루 대표 종목을 낮은 구조 위험만으로 고르면 당일 참여 강도와 재료 신선도가 약한 종목이 우선될 수 있었습니다.

## v6 경로

### 장중 추세 확인형

당일 상승률 10~15%, 소화율 0.30~1.00, 종가 위치 0.65 이상, 윗꼬리 0.35 이하, 몸통 0.60 이상, 테마 확산 0.80 이상, 테마 순위 5위 이내, 강한 후속주 2개 이상, 패턴 70점 이상 90점 미만을 요구합니다. 거래대금은 1,000억원 이상입니다.

### 직접 재료 미반영형

직접성 15점 이상, 신선도 3점 이상, 당일 등락률 -5~+3%, 종가 위치 0.35 이하, 구조 위험 5% 이하를 요구합니다. 회사명 또는 종목코드가 근거 문장에 직접 있어야 합니다. 계약·허가·임상 신청·주주환원처럼 구체적인 사건만 인정합니다.

### 직접 재료 반영형

직접성 14점 이상, 신선도 7점 이상, 강한 사건, 당일 상승률 3% 초과 10% 이하, 종가 위치 0.80 이상, 작은 윗꼬리, 몸통 0.55 이상, 구조 위험 6% 이하를 요구합니다.

### 테마 연속형

당일 상승률 4~9%, 소화율 0.30~0.60, 종가 위치 0.65~0.90, 테마 확산 0.90 이상, 테마 순위 3위 이내, 후속주 1개 이상과 거래량 비율 1.20 이상을 요구합니다.

## 성과 요약

- 8월 정확 호가 표본에서 v5는 4건 중 4건 양수, +3% 도달 2건, 정책수익 합계 +9.8641%였습니다.
- v6는 4건 중 4건 양수, +3% 도달 3건, 정책수익 합계 +10.6253%였습니다.
- 7월은 정확한 15시 18분과 09시 06분 호가가 없어 공식 성과가 아닙니다. 일봉 대용으로는 4건이 모두 장중 +3%에 닿고 다음 날 상승 마감했습니다.

## 운영 원칙

v6는 그림자 신호로만 기록합니다. v5와 동시에 계산하되 주문 기준으로 승격하지 않습니다. 40거래일과 완료 신호 20건을 모두 채우고, 마찰 0.3%를 차감한 평균과 중앙값이 양수일 때만 승격 여부를 다시 판단합니다.
