# 라르고 종가매매 스크리너 공개 사이트

라르고TV 공개영상 전수 분석에서 반복된 종가매매 흐름을 필수 게이트와 시간순 판정으로 구현한 공개 읽기 전용 스크리너입니다.

## 전략 판정 순서

1. 거래대금·거래량 급증·52주 고가 근접 종목을 후보로 수집합니다.
2. 관리·거래정지·시장경보 종목을 점수와 관계없이 제외합니다.
3. 섹터 대장 또는 강한 직접 재료를 확인합니다.
4. 기준봉·전고점·거래량·일봉 구조를 함께 판정합니다.
5. 장중 눌림을 소화하고 고가권을 재회복했는지 확인합니다.
6. 긴 윗꼬리와 과도한 고점 반납을 제외합니다.
7. 구조 손절선과 다음 날 시초 대응 계획을 계산합니다.
8. 공개 웹 호가와 체결은 참고값으로만 표시하고 실제 HTS 수동 확인을 요구합니다.

필수 게이트의 실패나 미확인은 품질점수로 상쇄하지 않습니다.

## 데이터 파이프라인

브라우저는 네이버증권을 직접 호출하지 않습니다. GitHub Actions가 로그인 없는 공개 읽기 전용 JSON을 저빈도로 수집해 정적 파일로 만들고 GitHub Pages에 배포합니다. 네이버 내부 JSON은 공식 API가 아니며 구조 변경·지연·오류 가능성이 있습니다.

HTTP 403 또는 429가 발생하면 자동 재시도를 하지 않습니다. 사이트는 자동 주문을 하지 않으며 `MANUAL_CONFIRM`도 매수 신호가 아닙니다.

## 초기 임계값

- 거래대금 500억 원 또는 거래대금 상위 20위
- 종가 위치 0.75 이상
- 윗꼬리 0.40 이하
- 구조 손절 거리 3.5% 이하

이 값은 라르고TV의 고정 공식이 아닙니다. 반복된 전략 방향을 컴퓨터가 판정하도록 만든 초기값이며 실제 모의 기록으로 보정해야 합니다.

## 배포

`bundles/largo_close_site_bundle.zip`에 HTML·스크리퍼·문서가 들어 있습니다. `.github/workflows/largo-close-site.yml`은 평일 장 마감 전후에 데이터를 새로 수집하고 GitHub Pages에 배포합니다.
