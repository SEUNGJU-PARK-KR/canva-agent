# 라르고 종가매매 스크리너

네이버증권의 로그인 없는 공개 읽기 전용 자료를 저빈도로 수집해 라르고TV식 종가 후보를 정적 사이트로 보여줍니다.

판정 순서는 다음과 같습니다.

`거래대금 후보 → 위험 종목 제외 → 대장·재료 → 차트 자격 → 고가권·윗꼬리 → 구조 손절 → HTS 수동 확인`

필수 게이트 실패는 점수로 상쇄하지 않습니다. 최고 자동 상태는 `진입 준비`이며 실제 HTS에서 대장·재료·호가·체결을 확인한 뒤 브라우저 로컬 상태로 `확인 완료`를 표시할 수 있습니다. 주문 기능은 없습니다.

GitHub Actions는 평일 14:35, 15:00, 15:15, 15:28 KST에 갱신을 시도합니다. GitHub Actions 일정은 정확한 시각보다 늦게 실행될 수 있습니다.

네이버증권 내부 경로는 공식 API가 아니며 예고 없이 바뀔 수 있습니다. 403 또는 429가 나오면 우회하거나 공격적으로 재시도하지 않습니다. 공개 웹 시세만으로 실제 호가 체결 소화를 확정하지 않습니다.
