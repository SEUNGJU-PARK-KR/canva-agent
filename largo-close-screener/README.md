# 라르고 종가매매 스크리너

네이버증권의 로그인 없는 공개 읽기 전용 자료를 저빈도로 수집해 라르고TV식 종가 후보를 정적 사이트로 보여줍니다. 주문과 계좌 연결 기능은 없습니다.

판정 순서는 다음과 같습니다.

`거래대금 후보 → 위험 종목 제외 → 대장·재료 → 차트 자격 → 고가권·윗꼬리 → 구조 손절 → 종가 보유 또는 익일 확인`

## 승률 개선 v4.1

기존 점수 하나로 매수 자격과 시가갭 가능성을 함께 표현하던 방식을 중단했습니다. 필수 게이트가 매수 자격을 정하고, 두 개의 실행 경로가 기회를 나눠 갖습니다.

종가 보유 핵심형은 S·A급 재료, C1·C3·C6 패턴, 당일 8~15% 상승, 종가 위치 0.75 이상, 윗꼬리 0.20 이하, 몸통 0.40 이상, 구조 위험 6% 이내, 주도 3위 이내, 매물 소화 0.45 이상을 요구합니다. 재료가 72시간 이내이거나 해당 테마 상승 비율이 75% 이상이어야 합니다.

초강한 마감형은 테마 상승 비율 75% 이상, 주도 2위 이내, 종가 위치 0.95 이상, 윗꼬리 0.05 이하, 몸통 0.55 이상일 때 매물 소화 기준을 0.30까지 허용합니다. 다른 필수 조건은 그대로 유지합니다.

익일 확인형은 강한 마감 구조를 갖췄지만 종가 보유 조건이 부족한 종목입니다. 종가에 보유하지 않습니다. 다음 날 갭이 3% 이상이면 추격하지 않으며 전일 종가 회복과 09:05·09:15 유지가 확인될 때만 검토합니다.

종가 보유형의 다음 날 청산 계획은 `+1%에서 50% → +2%에서 30% → 잔여 20% 추적`입니다. 10:30까지 +1%를 달성하지 못하고 전일 종가 아래에 있으면 잔여 물량을 정리하는 전진 검증 규칙을 사용합니다.

## 자동 실행 시각

조기 감시는 평일 13:38, 13:53, 14:08, 14:23, 14:33, 14:53, 15:04, 15:18, 15:23 KST에 실행됩니다. 정밀 갱신은 14:40, 15:00, 15:10, 15:18, 15:23, 15:28, 15:35 KST에 실행됩니다. GitHub Actions 일정은 정확한 시각보다 늦게 시작될 수 있습니다.

전진 검증은 다음 거래일 09:05, 09:15, 10:30, 15:35 KST에 읽기 전용 시세를 기록합니다. 목표선과 구조선이 같은 날 모두 관측되면 분봉 순서를 확인하기 전까지 결과를 확정하지 않습니다.

## 데이터 보정과 한계

과거 일봉이 존재하면 당일 신규 상장 미확인 경고를 해제합니다. 윗꼬리 0에 가까운 강한 양봉을 정상 통과시킵니다. 재료 시각은 원래 긍정 재료 제목과 실제 뉴스·공시 제목이 일치할 때만 인정합니다. 다른 회사의 공급계약이나 기계적 파생상품 공시는 재료로 사용하지 않습니다.

파일럿 백테스트의 성과 확인 거래일은 두 거래일뿐입니다. 같은 표본에서 규칙을 탐색하고 평가했으므로 외부 검증이 아닙니다. 최소 20~40거래일 전진 검증 전에는 확률이나 기대수익으로 해석하지 않습니다.

네이버증권 내부 경로는 공식 지원 API가 아니며 예고 없이 바뀔 수 있습니다. 403 또는 429가 나오면 우회하거나 공격적으로 재시도하지 않습니다.
