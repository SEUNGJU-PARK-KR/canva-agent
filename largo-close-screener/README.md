# 라르고 종가매매 스크리너

네이버증권의 로그인 없는 공개 읽기 전용 자료를 저빈도로 수집해 라르고TV식 종가 후보를 정적 사이트로 보여줍니다.

판정 순서는 다음과 같습니다.

`거래대금 후보 → 위험 종목 제외 → 대장·재료 → 차트 자격 → 고가권·윗꼬리 → 구조 손절 → HTS 수동 확인`

필수 게이트 실패는 점수로 상쇄하지 않습니다. 최고 자동 상태는 `진입 준비`이며 실제 HTS에서 대장·재료·호가·체결을 확인한 뒤 브라우저 로컬 상태로 `확인 완료`를 표시할 수 있습니다. 주문 기능은 없습니다.

`no-hoga.html`은 호가 관련 세 조건만 추천 판정에서 제거한 단일 HTML입니다. 종목 자격·재료·대장·일봉·매집 소화·종가 구조·진입가·구조 손절 게이트는 그대로 유지합니다.

후보를 종가 확정 뒤에 보여주지 않도록 조기 감시 파이프라인을 추가했습니다. 평일 13:38부터 후보를 준비도 순으로 표시합니다. 14:35 전에는 아직 관측할 수 없는 고가권·윗꼬리·마감 과정 조건을 삭제하지 않고 `PENDING`으로 둡니다. 관측 시간이 열리면 원래 필수 게이트로 다시 판정하며, 실패 종목은 자동으로 제외합니다.

조기 감시 갱신은 평일 13:38, 13:53, 14:08, 14:23, 14:33, 14:53, 15:04, 15:23 KST에 시도합니다. 기존 정밀 갱신은 14:40, 15:00, 15:10, 15:18, 15:28, 15:35 KST에 실행됩니다. GitHub Actions 일정은 정확한 시각보다 늦게 시작될 수 있습니다.

표시 단계는 `조기 감시 → 우선 준비 → 진입 준비 → 마감 유지 확인 → 종가 단일가 검토 → 종가 확정 검증` 순서입니다. 조기 감시는 매수 신호가 아닙니다. 15:20~15:30 종가 단일가에서는 필수 게이트와 구조 손절을 통과한 준비 후보만 검토합니다.

과거 스냅샷은 오늘 추천으로 표시하지 않습니다. 네이버증권 내부 경로는 공식 API가 아니며 예고 없이 바뀔 수 있습니다. 403 또는 429가 나오면 우회하거나 공격적으로 재시도하지 않습니다. 공개 웹 시세만으로 실제 호가 체결 소화를 확정하지 않습니다.
