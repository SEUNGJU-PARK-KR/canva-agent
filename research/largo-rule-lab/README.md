# 라르고 종가베팅 조건 실험실

5·6·7·8월에 보존된 후보와 다음 거래일 결과를 브라우저에서 즉시 다시 계산하는 읽기 전용 연구 도구입니다.

## 기능

- 위험률, 당일 등락률, 거래대금 소화율, 종가 위치, 윗꼬리, 몸통, 패턴 점수를 각각 켜고 끕니다.
- 테마 확산률·대장 순위와 재료 직접성·신선도를 수치로 변경합니다.
- 하루 선택 종목 수와 순위 기준을 바꿉니다.
- 목표수익, 손절, 왕복 비용과 위험비중을 함께 계산합니다.
- 한 조건을 여러 값으로 반복하는 민감도 검사를 브라우저 안에서 수행합니다.
- 설정 JSON과 날짜별 선택 거래 CSV를 저장합니다.

## 데이터 범위

- 2026년 5월 432건, 18거래일
- 2026년 6월 504건, 21거래일
- 2026년 7월 528건, 22거래일
- 2026년 8월 480건, 20거래일

5~7월은 신호일 종가와 다음 날 일봉을 사용한 대용 검증입니다. 8월은 확보된 6거래일에 한해 15시 18분 매도호가와 다음 날 09시 06분 전 매수호가를 사용합니다.

## 실행

공개 페이지는 `largo-rule-lab.html`입니다. 독립 실행 파일은 `generated/largo-rule-lab.html`에 보존합니다.

이 도구는 주문이나 계좌 연결을 하지 않습니다. 같은 월을 보며 조건을 찾고 성과를 재계산하면 과최적화가 생기므로 다른 월을 검증월로 남겨야 합니다.
