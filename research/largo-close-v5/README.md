## 목적

기존 +3% 통과 규칙을 20거래일 재구성 자료로 다시 검증하고, 다음 거래일 09시 06분 전 정책수익을 높이는 단순한 통과 구조를 찾았습니다.

- 2026년 8월 3일부터 31일까지 20거래일 480개 후보 재구성 자료
- 정확한 15시 18분 진입호가와 다음 거래일 09시 06분 전 결과호가가 함께 남은 6거래일 144건
- 기존 라르고 재료·종가 구조 점수와 안전 제외 결과

## v5 규칙

추세·거래대금형은 당일 상승률 10~15%, 최근 60거래일 최대 거래대금 대비 0.10~1.00, 15시 18분 스프레드 0.20% 이하를 요구합니다.

직접 재료형은 직접성 14점 이상, 신선도 3점 이상, 거래대금 비율 0.10~1.50, 스프레드 0.10% 이하를 요구합니다.

두 경로 모두 하드 제외가 없어야 합니다. 보통주만 허용하며 구조 위험 10%를 넘으면 차단합니다. 하루 여러 종목이 통과하면 위험거리, 스프레드, 거래대금 순서로 한 종목만 남깁니다.
