# 라르고 15:15 수동매매 대시보드

2026-09-07 작성. 사람이 후보를 확인하고 증권사 앱에서 직접 매매하는 읽기 전용 연구 화면입니다. 계좌 조회와 주문 기능은 없습니다. 기존 v5/v6와 별도 경로로 배포합니다.

## 사용

공개 경로는 `/canva-agent/manual-1515/`입니다. 당일 후보, 조건별 판정, 날짜별 종가→다음 거래일 시가 참고수익을 볼 수 있습니다. 실제 체결은 `내 매매 기록`에 따로 입력합니다. 이 기록은 브라우저 localStorage에만 저장하며 서버로 전송하지 않습니다. 기기 간 동기화는 없으므로 JSON 백업을 사용하세요.

새 신호 전에는 실제 신호·성과가 비어 있습니다. `예시 보기`의 예시기업 A/B/C는 화면 확인용 가상 데이터이며 실제 신호와 합산하지 않습니다. 화면 알림은 지원 브라우저에서 권한을 허용하고 페이지를 열어 놓았을 때만 작동합니다. 닫힌 페이지의 푸시 알림은 구현하지 않았습니다.

## 규칙

상승률 3~20%, 수집 가격×거래량 1,000억원 이상, 거래대금 소화 비율 5 이하, 테마 확산 70% 이상, 구조 위험거리 10% 이하입니다. 기본 보통주·가격·시가총액·시장경보·과거 일봉 오류 검사를 통과해야 합니다. 상승률 낮은 순서, 거래대금 큰 순서, 종목코드로 하루 한 종목을 선정합니다. 합산점수와 별도 캔들 형태 조건은 쓰지 않습니다.

직전 5분 중 확보한 자료로 15:15에 선정하는 별도 전진검증입니다. 최종 종가로 선정했던 과거 절충안의 승률이나 누적수익을 승계하지 않습니다. 공개 시세 공급자의 지연과 실제 체결은 검증되지 않았습니다.

## 예약과 시점 차단

한국 시각 14:57에 작업 시작을 예약합니다. 수집기를 준비한 뒤 15:10부터 수집하고 15:15에 선정합니다. 수집 완료가 15:15를 넘거나 발표 판단이 15:17을 넘으면 DATA_BLOCK으로 기록합니다. 후보 없는 날과 자료 오류를 구분합니다. 15:25 후에는 유효시간 종료를 표시합니다.

15:40에 종가를 보충하고 다음 거래일 09:12에 시가를 보충하도록 예약했습니다. GitHub Actions와 Pages 배포는 지연되거나 예약이 누락될 수 있으므로 정확한 15:15 게시를 보장하지 않습니다. 정시 신호가 확인되지 않을 때 오래된 종목을 다시 제시하지 않습니다. https://docs.github.com/en/actions/how-tos/troubleshoot-workflows

## 계산과 기록

참고 비용전 수익률(%)은 `(다음 거래일 시가/신호일 종가-1)*100`입니다. 비용후는 기본 0.30%포인트를 차감합니다. 실제 개인 체결수익은 입력한 체결가·수량·비용을 사용하며 참고수익과 분리합니다. 체결가를 입력하지 않았다는 이유로 종가에 매수했다고 간주하지 않습니다.

날짜별 선정은 불변입니다. 재실행·장후 정보로 종목을 교체하지 않습니다. 결과가 없는 가격은 빈칸이며 승률에 포함하지 않습니다. 거래정지 종목의 다음 시장 거래일 시가가 없으면 나중 날짜 시가로 대체하지 않습니다. 큰 권리변동 의심·가격 정정은 별도 검토 상태로 남깁니다. 시장 거래일은 대표 두 종목 일봉의 교집합 대용 달력으로 확인하며 확정 거래소 달력은 아닙니다.

복원된 소스는 manual1515.py, dashboard.html, test_manual1515.py, README.md입니다. 매 실행에서 단위검사 26개를 실행합니다. 원자료와 URL·시각·SHA-256은 90일 Actions 산출물에 보존합니다. 기존 이력을 가져오는 데 실패하면 빈 기록으로 덮어쓰지 않고 배포를 중단합니다.

로컬 화면 검사는 외부 접속이 제한된 환경에서 DOM과 저장소·요청 대역으로 수행했습니다. 실제 HTTP 통신·브라우저별 영구 저장·시세 수집의 실시간 성공을 증명하는 검사는 아닙니다. 첫 실제 거래일에 지연, 데이터 완전성, 종가와 시가 보충 성공을 따로 확인해야 합니다.
