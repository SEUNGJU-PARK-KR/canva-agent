# 라르고 15:15 스크리너와 자동 모의일지

2026-09-07 갱신. 공개 경로는 `/canva-agent/manual-1515/`입니다.

사람이 증권사 앱에서 매매할 수 있도록 후보를 보여주되, 일지는 사용자의 입력 없이 자동으로 작성합니다. 선정 종목을 당일 확정 종가에 매수하고 다음 시장 거래일 시가에 전량 매도했다고 가정합니다. 실제로 매매했는지와 무관하게 같은 규칙으로 기록합니다. 계좌 연결·조회·주문 기능은 없습니다.

## 입력 없이 이어지는 기록

15:15 신호가 고정되면 가상 매수 대기 일지가 생깁니다. 확정 종가가 보충되면 가상 매수일과 가상 매수가가 입력되고 가상 보유로 바뀝니다. 다음 시장 거래일 시가가 보충되면 가상 매도일과 가상 매도가 및 비용 전후 수익률이 입력됩니다.

선정일·종목·매수일·종가 매수가·매도일·시가 매도가·수익률·자동 메모를 표시합니다. 가상 매도 완료 기록만 모의 승률·평균·누적수익·최대낙폭에 포함합니다. 모든 상태를 날짜별 표에 남기며 일지 CSV와 JSON을 내려받을 수 있습니다. 브라우저를 닫아도 예약 수집과 일지 저장은 GitHub 작업에서 실행됩니다.

매수·매도 입력폼과 필수 개인 체결 기록은 제거했습니다. 기존 브라우저의 `largo-manual-1515-private-journal-v1` 값은 삭제하거나 서버로 보내지 않습니다. 값이 남아 있으면 이전 기록 백업 버튼만 표시합니다. 새 자동일지와 개인 기록을 섞지 않습니다.

## 가격과 손익의 의미

비용전 모의수익률(%)은 `(다음 시장 거래일 시가 / 신호일 확정 종가 - 1) * 100`입니다. 비용후는 고정된 왕복 비용 가정 0.30%포인트를 차감합니다. 15:15 관찰가격을 가상 매수가로 쓰지 않습니다. 실제 체결수익·잔고·수량을 가정하지 않습니다. 누적수익과 자산지수는 종목별 모의수익을 전액 재투자하는 비교용 계산입니다.

매수 시각을 정확히 15:30, 매도 시각을 정확히 09:00에 체결한 것처럼 기록하지 않습니다. 일봉 종가·시가를 가격 기준으로 썼다는 사실만 명시합니다. 가격이 없으면 빈칸으로 두며 0%로 만들지 않습니다. 다른 날의 시가를 대신 넣지 않습니다. 가격 정정·권리변동 의심이나 원본 수익과 재계산 불일치는 확인 상태로 남깁니다.

## 고정 선정 조건

상승률 3~20%, 수집 가격×누적거래량 1,000억원 이상, 소화 비율 5 이하, 테마 확산 70% 이상, 구조 위험거리 10% 이하입니다. 기존 보통주·가격·시가총액·시장경보·일봉 오류 검사를 유지합니다. 상승률 낮은 순서 → 거래대금 큰 순서 → 종목코드로 하루 한 종목을 고릅니다. 합산점수와 별도 캔들 형태 제한은 사용하지 않습니다.

자동일지 전환으로 선정 조건을 바꾸지 않았습니다. 15:10~15:15에 확보한 자료를 쓰는 별도 전진검증입니다. 최종 종가를 보고 선정했던 과거 절충안의 수익률이나 승률을 승계하지 않습니다.

## 예약과 시점 차단

한국 시각 14:57 준비 시작, 15:10 수집 시작, 15:15 선정 목표입니다. 수집 완료가 15:15를 넘거나 내부 발표 판단이 15:17을 넘으면 DATA_BLOCK으로 처리합니다. 15:25 이후에는 신호 유효시간 종료를 표시합니다.

15:40에는 종가를 보충하고 다음 거래일 09:12에는 시가를 보충하도록 기존 예약을 유지합니다. 09:12는 수집·기록 갱신 시각이며 매도 가격은 평가일 시가입니다. 예약 누락·시세 지연·Pages 배포 지연으로 정시 표시를 보장하지 않습니다. 공개 시세 제공자의 지연과 실제 체결은 검증하지 못했습니다. 시장 달력은 대표 두 종목 일봉의 교집합 대용값이며 공식 거래소 달력은 아닙니다.

화면 알림은 지원 브라우저에서 권한을 허용하고 페이지를 열어 둔 동안만 작동합니다. 닫힌 페이지의 푸시 알림은 구현하지 않았습니다. 알림과 무관하게 자동일지는 서버에 저장합니다.
